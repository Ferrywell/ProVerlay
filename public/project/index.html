        Custom CSS

        Optional stylesheet for this project, loaded by the render output after the built-in styles, so it can restyle any overlay (for example a brand-specific scorebug). Saving updates every open render live.

        Class names and variables

        Every overlay is a layer .graphic-layer[data-id="<widget id>"][data-type="<type>"] containing .graphic.graphic--<type>, for example .graphic--matchScoreboard, .graphic--hockeyScorebug, .graphic--customTicker, .graphic--streamCountdown, .graphic--lowerThirdShow, .graphic--quizShow, .graphic--message, .graphic--f1Timing.

        • Match score: .match-board, .mb-team, .mb-score, .mb-clock, .clock-pill
        • Hockey scorebug: .hockey-bug, .hockey-arm--home, .hockey-arm--away, .hockey-code, .hockey-score, .hockey-clock, .hockey-clock__time, .hockey-clock__period
        • Other: .countdown-board, .ticker-default, .lt-board, .quiz-board, .quiz-opt, .f1-tower, .f1-row
        • Variables: --primary, --secondary, --text, --background, --brand-font, --font-size, --padding, --canvas-w, --canvas-h

        Use project assets with relative URLs, e.g. background: url(assets/plate.png). @import is removed on save. Custom CSS is trusted local content: only paste CSS you understand, and avoid remote URLs so the overlay keeps working offline. Max 200 KB.
