Data

Data sources

Names, titles, ticker lines, quiz questions or image lists from a spreadsheet. ProVerlay keeps the last good copy in the project, so the show keeps working without internet.

Google Sheet

Paste the link of a sheet shared as “anyone with the link”, or a Publish to web CSV link. No Google login needed.

CSV or Excel file

Upload a .csv (comma, semicolon or tab separated) or .xlsx file. It is stored in the project; upload a new version any time.

Linked file on this computer

ProVerlay re-reads the file as soon as it is saved. Only possible on the ProVerlay computer itself.

Variables

Use them in any text field as {{event.title}}. Letters, digits, . _ and -. Graphics on air update right away.

Variables from a source

A sheet with a key and a value column becomes variables. They override project variables with the same name.

Built-in variables

Allowed hosts

Sheet links are fetched over https from Google Sheets only. Add other hosts here (one per line, *.example.com for subdomains). Private network addresses are never fetched. Only changeable on the ProVerlay computer.
